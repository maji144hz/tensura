จากไฟล์จริงในเครื่อง พร้อมอ้างอิงไฟล์ทุกหัวข้อ

หน้าแรก สกิลทั้งหมด ม็อบ / เรทเกิด แร่ / วัสดุ บอส / มิติ ระบบสำคัญ เควสไอเทม / อีโว

เริ่มด่วน 5 นาที

  1. เลือกเผ่า 1 ใน 33 เผ่า
  2. กด B → สกิลเทาใส่ช่อง → Z / X / C เรียน
  3. ฆ่ามอนเก็บ EP (ได้ 3% ของเหยื่อ)
  4. EP 2,000 → Telepathy / 3,000 → Strength / 5,000 → Coercion
  5. ขุด Magic Ore ด้วย Netherite ขึ้นไป

เลือกหัวข้อ

สกิลทั้งหมด + เงื่อนไขครอบครอง
