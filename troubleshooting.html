1. เข้าโลกแล้วแครช Ticking entity — Zombie Horse

crash-2026-09-29_12.49.33-server.txt:16 NullPointerException: WrappedGoal.isRunning() ที่ GoalSelector.tickRunningGoals — ตัวต้นเหตุคือม้าซอมบี้ ID 10004 ที่ -141,60,-1878 มีซอมบี้ขี่ (:64-70) ชน mixin servercore activation_range.inactive_ticks.GoalSelectorMixin

แก้: ปิด activation_range / inactive_ticks ใน config ServerCore หรือถอด servercore-neoforge-1.5.5+1.21.1.jar เทสก่อน → เข้าเกม /kill ม้าตัวนั้น (selector ระยะ) หรือลบด้วย NBT editor → เปิดกลับได้

2. เปิดเกมไม่ขึ้น — Sophisticated Backpacks

crash-2026-09-28_02.36.56-client.txt NoClassDefFoundError: UpgradeGuiManager$IUpgradeInventoryPartFactory ตอน RegisterMenuScreensEvent — Backpacks กับ Core เวอร์ชันไม่ตรงกัน

แก้: อัปเดต sophisticatedbackpacks + sophisticatedcore เป็นคู่เวอร์ชันเดียวกันพร้อมกัน อย่าอัปทีละตัว

3. ปุ่มชนกัน (B / H)

B = Tensura GUI ชน Tom's Storage terminal • H = กระเป๋า ชน Accessories/Crest (options.txt:268) — แนะนำ B=Tensura, G=Tom's, H=กระเป๋า, .=Accessories

4. คำถามซ้ำ

Metal Slime ต้อง Magic Ore 100 ไม่ใช้ EP[2] • OrcLord ใช้ Royal Blood 10 ไม่ใช้ EP[3] • Feldway ต้อง Pure 3x3 + Mithril กลางในมิติ Paths[1] • Charybdis เลี้ยง Core ถึง 100k แล้วฟัก (block_config:16-28)

5. อ่านแครชเอง
